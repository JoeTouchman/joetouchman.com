JoebotHand.

A 3D-printed, five-finger robotic hand that copies your hand in real time. A web app tracks your fingers through a phone camera and sends each finger's position over Wi-Fi to an ESP32-S3, which drives five servos that pull the fingers closed with string.

  • ESP32-S3
  • MediaPipe hand tracking
  • HTTPS + WebSocket
  • 5 MG90S servos
  • 3D printed
Code on GitHub ↗ Try the live demo

How it works

On the phone

Cameralive video
MediaPipe21 landmarks in 3D
Curl math0–100% per finger
Wi-Fi · secure WebSocket · ~30×/s

In the hand

ESP32-S3limits + watchdog
5 servos50 Hz PWM
Fingersstring tendons

1 · Tracking

MediaPipe finds 21 points on the hand in 3D. Each finger's curl is the sum of its joint bend angles, with side-to-side spread removed, so it doesn't depend on how the hand is turned. Each finger is calibrated between an open and a curled pose.

2 · Link

The phone joins the hand's own Wi-Fi hotspot and opens the app the ESP32 serves. The five curl values are sent over a secure WebSocket about 30 times a second.

3 · Firmware

The ESP32-S3 converts each percentage to a servo angle inside that finger's safe limits and drives the servo with hardware PWM. A watchdog opens the hand if the phone disconnects.

Challenges

Camera vs. local network

Browsers only allow the camera on secure (HTTPS) pages, but a secure page can't talk to an insecure device like the hand, so hosting the app online didn't work.

Fix: the ESP32 serves the app itself over HTTPS, with a real certificate for a domain I own that points at the hand's local address. Phones open it with no warning and no internet.

Servo library bug

With the ESP32Servo library, moving one finger moved several.

Fix: I read the chip's pin routing directly, found the library was sending several servos' signals to the same output, and replaced it with direct hardware PWM.

Fitting the model on the chip

The app has to work with no internet, so the web app, MediaPipe's WebAssembly runtime and the model all live in the ESP32's flash.

Fix: about 9 MB gzipped into a 12 MB partition, served with download progress and cached on the phone.

Clips

Forearm versions

  1. Original. The plain forearm from the tutorial design.
  2. First redesign. A round base so the hand stands on its own, a press fit so the hand slides on and off, and a hole for the power button.
  3. Current. A hollowed base so the servos get their full range of motion, exits for the wires, and corrected dimensions.

Parts and credit

  • ESP32-S3 DevKitC-1 (16 MB flash, 8 MB PSRAM)
  • 5 × MG90S servos on a 5 V 5 A supply
  • Braided fishing line as tendons, elastic cord to spring the fingers back open
  • Buzzer for startup and connection sounds, and a status light in the power button

The hand and finger design comes from Viral Science's flex-sensor robot hand tutorial. My work: the redesigned forearm and stand, the wiring, the move from Arduino to ESP32-S3, camera tracking in place of flex sensors, the self-hosted web app, and the firmware. The wiring schematic, firmware and STL are in the GitHub repository.
