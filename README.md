# joetouchman.com

Source for my personal website: [joetouchman.com](https://joetouchman.com).

Plain HTML, CSS and JavaScript. No framework and no build step.

```
index.html        the page
css/style.css     all styling
js/main.js        scroll effects, counters, video handling, contact links
js/hand-demo.js   the "Try it" hand-tracking demo
assets/           web-ready images and video
```

## Run it locally

```bash
python3 -m http.server 4321
```

Then open http://localhost:4321.
